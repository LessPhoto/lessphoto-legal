# LessPhoto Blog 写作区

这里主要存放中文写作大纲，不是 Astro 的正式发布目录。新建文章时，按季度选择文件夹，复制根目录的 `YYYYMMDD-博客文章模板.md`，重命名后开始写作。文章图片放在同一季度文件夹内对应的日期图片文件夹中，完成中文初稿后再整理成正式 Blog。

目录按季度管理，文件夹内直接平铺文章和图片文件夹：

```text
blog/
├── 2026Q4/
│   ├── 20261029-文章主题.md
│   └── 20261029-图片/
├── 2027Q1/
│   ├── 20270115-文章主题.md
│   └── 20270115-图片/
├── YYYYMMDD-博客文章模板.md
└── README.md
```

季度文件夹使用 `YYYYQn` 格式，例如 `2026Q4`、`2027Q1`。每个季度的文章通常不多，直接集中管理即可。

## 正式发布的文章

正式发布的多语言文章位于：

```text
src/content/blog/<slug>/
├── en.md
├── zh-hans.md
└── zh-hant.md
```

这里的文章可能需要手动修改，修改后会直接影响网站内容。
