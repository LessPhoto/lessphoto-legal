# LessPhoto Blog 前期协作稿

这里主要存放 Blog 前期协作稿，是作者与 AI/Agent 沟通和优化文章的工作区，不是 Astro 的正式发布目录。新建文章时，按季度选择文件夹，复制根目录的 `YYYYMMDD-博客文章模板.md`，重命名后开始写作。文章图片放在同一季度文件夹内对应的日期图片文件夹中，完成定稿后再整理成正式 Blog。

## 从前期协作稿整理为正式 Blog

- 正式 Blog 放在 `src/content/blog/<slug>/`，按 `en`、`zh-hans`、`zh-hant` 分别整理。
- 落地时不扩写，不改变原稿目的和语义；英文翻译保持简洁，尽量复用已有正式文章的结构和格式。
- 各语言页面只保留对应地区的价格表和必要说明。
- Markdown 表格中的 `✓` 和 `✓✓` 应在正式页面中使用明显的绿色样式。

## 表格样式

- 普通表格使用共享表格样式，第一列略微加深，用于突出对比项。
- VS 表格使用 `.blog-table-vs`，黄色列通过 `data-vs-column` 配置，黄色左侧为蓝色，右侧为紫色。
- 以上两种样式都需要保留；除非明确要求，不要主动删除、合并或改成同一种样式。

目录按季度管理，文件夹内直接平铺文章和图片文件夹：

```text
blog前期协作稿/
├── 2026Q4/
│   ├── 20261029-文章主题.md
│   └── 20261029-图片/
├── 2027Q1/
│   ├── 20270115-文章主题.md
│   └── 20270115-图片/
├── YYYYMMDD-博客文章模板.md
└── README.md
```

季度文件夹使用 `YYYYQn` 格式，例如 `2026Q4`、`2027Q1`。每个季度的文章通常不多，直接集中管理即可。

## 正式发布的文章

正式发布的多语言文章位于：

```text
src/content/blog/<slug>/
├── en.md
├── zh-hans.md
└── zh-hant.md
```

这里的文章可能需要手动修改，修改后会直接影响网站内容。
